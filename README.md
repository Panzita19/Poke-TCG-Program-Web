# Poke-TCG-Program-Web

Nuestra API ofrece un sistema de intercambio de cartas de pokemon tomando como inspiracion el Juego De Cartas Coleccionables de Pokemon.

Tienes que desplegar el repositorio en Github Pages para visualizar el front y aprovechar sus capacidades.

Para el uso de WebSocket necesitas iniciar un servidor en Render, que ofrece un servicio gratuito para ello.

Necesitas subir la carpeta WebSocket-Server a un repositorio aparte y conectarlo con Render.
